posture-bot · multi-bot serverless architecture

Any number of bots, each sending its own image hourly at one shared random second · Lambda + EventBridge Scheduler + DynamoDB + SSM · eu-central-1

Subscribe path

  • • all bots share one URL; bot identified by its secret
  • • admin bot on its own URL, answers super admin only
  • • /start: subscribe to that bot, photo now
  • • channel: bot admin + Post messages → subscribe
  • • admin sends a photo → stored file_id, used at once

Hourly send

  • • planner keeps one-time schedules 24 h ahead
  • • schedule fires → one invocation per enabled bot
  • • broadcast sleeps to the exact second
  • • same second for all bots, 25 msg/s each
  • • each bot sends its own image by file_id

Failure handling

  • • Scheduler retries up to 2 min, then DLQ
  • • missed slots are dropped, never sent late
  • • per-bot lease + sent log; one bad bot can't block others
  • • a started round always finishes
  • • SSM edits sync within seconds; bad tokens → status
